# Training an AI Model

Training is how AI learns — the same way humans learn from experience.

## 1. Collecting Data
AI needs:
- Conversations  
- Books  
- Images  
- Audio  
- Code  
- Real-world examples  

Better data = smarter AI.

## 2. Preprocessing
Data is cleaned:
- Removing duplicates  
- Fixing errors  
- Standardizing formats  

## 3. Training Process
The AI adjusts billions of parameters using:
- Gradient descent  
- Backpropagation  

Every training step makes the model slightly smarter.

## 4. Evaluation
AI is tested on:
- Accuracy  
- Toxicity  
- Bias  
- Reasoning  
- Safety  

## 5. Fine-Tuning
Extra training for special tasks like:
- Chatbots  
- Medical tools  
- Coding assistants  
- Legal AI
