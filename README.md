# AI Book Web App

This is a full-stack Humanoid AI Book Web App featuring a Docusaurus-based React frontend and a FastAPI (Python) backend.

## Project Structure

- `frontend/`: Docusaurus-based React application.
- `backend/`: FastAPI application.

## Getting Started

### Frontend

Navigate to the `frontend/` directory and run `npm install` followed by `npm start`.

### Backend

Navigate to the `backend/` directory and run `pip install -r requirements.txt` followed by `uvicorn main:app --reload`.
